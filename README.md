# llm_check_bot

Telegram-бот, который проверяет сообщения выбранных пользователей на «нейрослоп» (текст, сгенерированный нейросетью) с помощью Claude и отвечает на подозрительные сообщения.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. **Отключите privacy mode**: `/setprivacy` → выберите бота → `Disable`. Иначе бот не увидит обычные сообщения в группе.
3. Добавьте бота в группу.
4. Скопируйте `.env.example` в `.env`, впишите токены и запустите:

```bash
cp .env.example .env
go run .
```

`.env` в `.gitignore` и не попадёт в репозиторий. Переменные, уже заданные в окружении, имеют приоритет над `.env`.

Узнать свой Telegram ID: напишите боту `/start` в личку.

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота |
| `ANTHROPIC_API_KEY` | — | ключ Claude API |
| `WATCHED_USERS` | — | ID и/или @username через запятую |
| `SLOP_THRESHOLD` | `70` | порог 0–100, с которого бот отвечает |
| `MIN_MESSAGE_LENGTH` | `60` | короткие сообщения не проверяются |
| `STYLE_HISTORY` | `20` | сколько последних «человеческих» сообщений пользователя помнить как образец его стиля (0 — выключить) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель Claude |

Бот запоминает обычные сообщения каждого отслеживаемого пользователя (отдельно по чатам) и передаёт их Claude как образец стиля: резкая смена манеры письма — сильный сигнал. История хранится в памяти и сбрасывается при перезапуске. Если сообщение отредактировали, бот проверит его заново, но второй раз не ответит.

Все оценки (в том числе ниже порога) пишутся в лог — удобно для подбора порога.
