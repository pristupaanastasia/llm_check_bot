# llm_check_bot

Telegram-бот, который проверяет сообщения выбранных пользователей на «нейрослоп» (текст, сгенерированный нейросетью) и отвечает на подозрительные сообщения. Оценку даёт локальная модель [Qwen3](https://ollama.com/library/qwen3), запущенная через [Ollama](https://ollama.com) прямо на вашем компьютере: без платных API, сообщения из чата никуда не уходят.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. **Отключите privacy mode**: `/setprivacy` → выберите бота → `Disable`. Иначе бот не увидит обычные сообщения в группе.
3. Добавьте бота в группу.
4. Установите Ollama и скачайте модель (около 9 ГБ, нужно ~16 ГБ памяти):

```bash
brew install ollama
brew services start ollama   # или `ollama serve` в отдельном терминале
ollama pull qwen3:14b
```

   Если памяти меньше, возьмите `qwen3:8b` (~5 ГБ) и укажите `OLLAMA_MODEL=qwen3:8b`.
5. Скопируйте `.env.example` в `.env`, впишите токен бота и список пользователей, затем запустите:

```bash
cp .env.example .env
go run .
```

`.env` в `.gitignore` и не попадёт в репозиторий. Переменные, уже заданные в окружении, имеют приоритет над `.env`.

Узнать свой Telegram ID: напишите боту `/start` в личку.

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота |
| `OLLAMA_URL` | `http://localhost:11434` | адрес Ollama |
| `OLLAMA_MODEL` | `qwen3:14b` | модель в Ollama |
| `WATCHED_USERS` | — | ID и/или @username через запятую (лучше ID: username можно сменить, и его займёт другой человек) |
| `SLOP_THRESHOLD` | `70` | порог 0–100, с которого бот отвечает |
| `MIN_MESSAGE_LENGTH` | `60` | короткие сообщения не проверяются |
| `STYLE_HISTORY` | `20` | сколько последних «человеческих» сообщений пользователя помнить как образец его стиля (0 — выключить) |
| `MAX_CONCURRENT_CHECKS` | `4` | сколько запросов к модели может идти одновременно |
| `SLOP_IMAGE` | `assets/sticker.webp` | картинка для ответа на нейрослоп: `.webp` отправляется стикером, остальное (`.png`, `.jpg`) — фото с подписью; если файла нет — бот отвечает текстом |
| `DEBUG` | — | любое значение — писать в лог каждое полученное сообщение (без текста) и причину пропуска |

Бот запоминает обычные сообщения каждого отслеживаемого пользователя (отдельно по чатам) и передаёт их модели как образец стиля: резкая смена манеры письма — сильный сигнал. История хранится в памяти и сбрасывается при перезапуске. В образец стиля попадают только короткие сообщения и сообщения с явно низким баллом (меньше половины порога). Пересланные сообщения бот не проверяет и не запоминает. Если сообщение отредактировали, бот проверит его заново; если на него уже был ответ — не проверяет и второй раз не отвечает.

Текст сообщения экранируется перед отправкой в модель, а из объяснения, которое бот пишет в чат, вырезаются ссылки и @упоминания — так через сообщение нельзя «уговорить» модель или заставить бота написать что-то от своего имени. Токен Telegram вырезается из сетевых ошибок, чтобы не попасть в логи.

Все оценки (в том числе ниже порога) пишутся в лог — удобно для подбора порога.

## Облачная модель (необязательно)

Вместо локальной модели бот умеет работать через облачный API Claude: `LLM_PROVIDER=claude`, `ANTHROPIC_API_KEY=...`, модель задаётся в `CLAUDE_MODEL`. API оплачивается отдельно от подписки, поэтому по умолчанию используется Ollama.
